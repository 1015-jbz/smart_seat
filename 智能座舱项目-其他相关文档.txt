================================================================================

1.1 部署架构总览
----------------------------------------------------------------
  浏览器 (React 前端)
      │
      ├── :8000/api/v1/*  ──→  FastAPI 后端 ──→ SQLite
      │                          │
      │                          ├── DeepSeek API（AI 对话）
      │                          ├── Open-Meteo（天气）
      │                          └── 高德/pconline/ipinfo（IP 定位）
      │
      ├── :7861/video_feed ──→  Flask 摄像头 ──→ USB/内置摄像头
      │      /api/state              │
      │                          ├── MediaPipe 468 关键点
      │                          ├── ONNX EfficientNet-B2
      │                          └── Haar Cascade（降级）
      │
      └── ws://:8000/ws/vehicle ──→ WebSocket 车辆数据推送

  龙芯 3A6000 笔记本部署架构：
    使用笔记本内置摄像头、麦克风、扬声器，start.sh 一键启动全部 4 个服务，
    龙芯浏览器访问 http://localhost:5173 即可使用完整系统。

1.2 服务进程清单
----------------------------------------------------------------
  进程            端口  启动方式            说明
  --------------  ----  ------------------  ----------------------
  FastAPI 后端    8000  python main.py      业务 API + WebSocket
  Flask 摄像头    7861  python camera_server.py  视频流 + 疲劳/表情
  TTS 服务        8787  python tts_server.py      语音合成
  Vite 前端       5173  npm run dev         开发态前端

  龙芯 3A6000 一键启动：start.sh 同时启动以上全部 4 个服务。

1.3 生产部署建议
----------------------------------------------------------------
  (1) 前端构建：npm run build 生成 dist/，由静态服务器托管；
      start.bat/start.sh 已内置"缺 dist 自动补构建"逻辑；
  (2) 进程守护：生产环境建议用 systemd / supervisor 守护四个进程；
  (3) 反向代理：Nginx 统一 80/443 入口，转发到各端口；
  (4) 数据库备份：SQLite 文件位于 backend/data/，定期冷备即可；
  (5) 日志：后端 logging 输出到 stdout，可重定向到日志文件。

1.4 运维检查清单
----------------------------------------------------------------
  - 健康检查：curl http://localhost:8000/api/health 应返回 {"status":"ok"}；
  - 摄像头流：浏览器访问 http://localhost:7861/video_feed 应看到画面；
  - 前端：访问 http://localhost:5173 应正常加载；
  - 磁盘：SQLite 与音乐目录注意空间；
  - 外网：AI/天气/定位/在线曲库需网络可达。

1.5 龙芯 3A6000 部署流程
----------------------------------------------------------------
  龙芯 3A6000 笔记本（LoongArch64 + UOS）完整部署流程：

  前提条件：
    · UOS 系统已安装并可正常上网；
    · 已安装 git（apt install git）；
    · 已安装 Node.js 18+（apt install nodejs npm）。

  步骤 1：克隆代码
    git clone https://github.com/1015-jbz/smart_seat.git
    cd smart_seat

  步骤 2：一键安装
    chmod +x setup.sh
    ./setup.sh

    setup.sh 自动完成：
      · 检测 LoongArch64 架构；
      · 安装 Python 3.10+ 环境（优先使用系统 Python 3.11+）；
      · 创建虚拟环境并安装 Python 依赖；
      · 安装 LoongArch64 原生 wheels（onnxruntime、mediapipe、opencv、PyTorch）；
      · 安装 Node.js 依赖并构建前端 dist；
      · 生成 backend/.env 配置模板。

  步骤 3：配置 API Key
    vim backend/.env
    # 填入 DEEPSEEK_API_KEY

  步骤 4：一键启动
    chmod +x start.sh
    ./start.sh

    start.sh 同时启动：
      · FastAPI 后端（8000）
      · Flask 摄像头服务（7861）
      · TTS 服务（8787）
      · Vite 前端（5173）

  步骤 5：打开龙芯浏览器
    访问 http://localhost:5173，即可使用完整系统。

第二部分  API 接口文档
================================================================================

2.1 通用约定
----------------------------------------------------------------
  - 前缀：/api/v1
  - 返回格式：JSON（UTF-8）
  - 分页参数：page（默认 1，最小 1）、page_size（默认 20，最大 100）
  - 错误处理：全局异常兜底，500 返回 {"detail":"服务器内部错误，请稍后重试"}

2.2 系统
----------------------------------------------------------------
  GET /api/health
    返回 {"status":"ok"}，用于健康检查。

2.3 车辆数据（/vehicle）
----------------------------------------------------------------
  GET /api/v1/vehicle/state
    返回实时车辆状态：speed/rpm/fuel/temperature/tire_pressure[4]/behavior_events。
  POST /api/v1/vehicle/state
    记录一次车辆状态快照到数据库。
  GET /api/v1/vehicle/history?page=&page_size=
    返回历史车辆状态（分页，倒序）。
  WS /ws/vehicle
    每秒推送 {timestamp,speed,rpm,fuel,temperature,tire_pressure[4]}。

2.4 安全监控（/safety）
----------------------------------------------------------------
  GET /api/v1/safety/fatigue?driving_minutes=&continuous_minutes=&break_count=
    返回 {score,level,advice,is_night,timestamp}。
  POST /api/v1/safety/fatigue/event
    记录一次疲劳事件，返回事件对象。
  GET /api/v1/safety/fatigue/history?page=&page_size=
    疲劳事件历史（分页倒序）。
  GET /api/v1/safety/stats
    返回总驾驶时长、疲劳事件数、平均疲劳分、等级分布、近 7 天事件数。

2.5 表情识别（/emotion）
----------------------------------------------------------------
  GET /api/v1/emotion/records?page=&page_size=
    情绪记录历史。
  POST /api/v1/emotion/records
    记录一次情绪识别结果。
  GET /api/v1/emotion/stats?days=
    情绪统计：占比、平均置信度、每日趋势。
  POST /api/v1/emotion/detect
    入参 {image_base64, detect_face}，返回 {emotion_en,emotion_zh,emoji,color,
    confidence,face_box,face_detected,all_scores,elapsed_ms}。

2.6 驾驶记录（/driving）
----------------------------------------------------------------
  GET /api/v1/driving/sessions
    驾驶会话列表（分页）。
  POST /api/v1/driving/sessions
    创建会话。
  GET /api/v1/driving/sessions/{id}
    会话详情（含疲劳事件）。
  PUT /api/v1/driving/sessions/{id}/end
    结束会话，自动计算时长与疲劳事件数。
  GET /api/v1/driving/stats
    驾驶统计：总里程、总时长、平均/最高速度、疲劳事件总数。

2.7 智能对话（/chat）
----------------------------------------------------------------
  POST /api/v1/chat
    入参 {message, context}，返回 {reply, source}，
    source ∈ {deepseek, fallback}。

2.8 天气代理（/weather）
----------------------------------------------------------------
  GET /api/v1/weather?lat=&lon=
    实时天气 + 7 天预报。
  GET /api/v1/weather/city/{city_name}
    按城市名查天气。
  GET /api/v1/weather/cities
    内置城市列表。

2.9 定位代理（/location）
----------------------------------------------------------------
  GET /api/v1/location
    IP 定位（高德优先，pconline 兜底）。
  POST /api/v1/location/regeo
    入参 {latitude,longitude}，逆地理编码街道级地址。
  GET /api/v1/location/cities
    城市坐标库。
  GET /api/v1/location/search?city=
    城市/区县/街道搜索（高德地理编码）。

2.10 音乐娱乐（/music）
----------------------------------------------------------------
  GET /api/v1/music/library
    完整曲库（本地 + 内置演示）。
  GET /api/v1/music/search?q=
    按歌名/歌手/风格搜索。
  GET /api/v1/music/stream/{track_id}
    流式播放本地音频（支持 Range 拖动）。
  POST /api/v1/music/refresh
    重新扫描本地音乐目录。
  GET /api/v1/music/online/search?q=&limit=
    在线曲库搜索（Jamendo CC 授权）。
  GET /api/v1/music/online/hot?tag=&limit=
    在线曲库热门榜。

第三部分  数据字典
================================================================================

3.1 车辆状态（VehicleState）
----------------------------------------------------------------
  字段            类型      说明
  --------------  --------  ----------------------
  speed           float     车速（km/h）
  rpm             float     发动机转速（r/min）
  fuel            float     油量（%）
  temperature     float     水温（℃）
  tire_pressure_fl/fr/rl/rr  float  四轮胎压（bar）
  timestamp       datetime  记录时间

3.2 疲劳事件（FatigueEvent）
----------------------------------------------------------------
  字段              类型      说明
  ----------------  --------  ----------------------
  id                int       主键
  session_id        int       所属驾驶会话
  fatigue_score     int       疲劳评分（0~100）
  level             str       等级 normal/warning/high/critical
  duration_seconds  float     事件持续秒数
  action_taken      str       已采取动作描述
  timestamp         datetime  发生时间

3.3 情绪记录（EmotionRecord）
----------------------------------------------------------------
  字段        类型      说明
  ----------  --------  ----------------------
  id          int       主键
  emotion     str       情绪标签
  confidence  float     置信度（0~1）
  source      str       识别来源
  timestamp   datetime  记录时间

3.4 驾驶会话（DrivingSession）
----------------------------------------------------------------
  字段                类型      说明
  ------------------  --------  ----------------------
  id                  int       主键
  start_time          datetime  开始时间
  end_time            datetime  结束时间
  distance_km         float     里程（km）
  max_speed           float     最高速度
  avg_speed           float     平均速度
  duration_minutes    float     时长（分钟）
  fatigue_events_count int     疲劳事件数

3.5 表情类别枚举
----------------------------------------------------------------
  英文        中文     emoji  主题色
  ----------  ------  ------  --------
  happy       开心    😊      #fbbf24
  sad         悲伤    😢      #60a5fa
  angry       愤怒    😠      #f87171
  surprised   惊讶    😮      #a78bfa
  fearful     恐惧    😨      #34d399
  disgusted   厌恶    🤢      #94a3b8
  neutral     平静    😌      #34d399
  fatigue     疲劳    😴      #fb923c

3.6 疲劳等级枚举
----------------------------------------------------------------
  等级      中文      说明                语音告警
  --------  --------  ------------------  ----------
  normal    正常      状态良好            无
  warning   轻度      哈欠/轻度疲劳       有
  high      中度      闭眼 >2s            有
  critical  重度      闭眼 >4s            有（循环告警）

第四部分  硬件采购清单与适配说明
================================================================================

4.1 目标硬件平台
----------------------------------------------------------------
  项目面向龙芯（LoongArch）国产化平台，最终部署硬件：
  - 龙芯 3A6000 笔记本（8GB+ RAM）
  - 操作系统：UOS（统一操作系统）
  - 处理器特性：支持 LSX（128 位 SIMD）和 LASX（256 位 SIMD）指令集
  - 浏览器：龙芯浏览器（基于 Chromium 138 内核，原生 LoongArch64）

  龙芯 3A6000 处理器技术规格：
    · 架构：LoongArch64
    · 指令集：LSX（128 位 SIMD）+ LASX（256 位 SIMD）
    · 内存支持：DDR4，最大 32GB
    · 集成显卡：支持基本图形渲染
    · 功耗：25W TDP，适合笔记本平台

4.2 硬件适配要点
----------------------------------------------------------------
  (1) 龙芯 3A6000 支持 LSX/LASX SIMD 指令集，可流畅运行现代浏览器
      （龙芯浏览器 Chromium 138 内核）及 AI 推理框架，无兼容性问题；
  (2) onnxruntime / mediapipe / opencv / PyTorch 均已发布 LoongArch64
      预编译 wheels，无需降级，全功能可用；
  (3) 8GB+ 内存满足前端构建、后端服务、AI 模型加载等多进程并行需求；
  (4) 笔记本内置摄像头、麦克风、扬声器均可免驱使用，无需外接设备。

4.3 配件建议
----------------------------------------------------------------
  组件        建议                   用途
  ----------  ---------------------  ------------------
  摄像头      笔记本内置 / USB 720P  疲劳/表情检测
  麦克风      笔记本内置 / 全向降噪  语音识别
  扬声器      笔记本内置 / 车规级    语音播报
  显示屏      笔记本内置 / 7~10 英寸  交互界面
  存储        内置 SSD / SD 卡 8GB+  系统 + 数据

4.4 轻量化部署定位
----------------------------------------------------------------
  本项目属"轻量化端侧 AI 部署"：核心检测（人脸/EAR/MAR）在端侧完成，
  表情分类模型（EfficientNet-B2）已量化/精简，云端仅承担大模型对话
  与天气/定位/在线曲库等需要联网的能力，符合"端云协同"的轻量化思路。

  在龙芯 3A6000 平台上，Whisper STT 语音识别已可端侧本地运行，
  进一步向纯端侧轻量化部署迈进。

第六部分  安全与隐私说明
================================================================================

6.1 数据安全
----------------------------------------------------------------
  (1) 摄像头画面仅在本地处理，不上传云端（表情检测走本地 ONNX）；
  (2) AI 对话仅发送用户文本到 DeepSeek API，不含图像/位置敏感信息；
  (3) 数据库 SQLite 仅存驾驶/疲劳/情绪统计，不含原始视频。

6.2 隐私合规
----------------------------------------------------------------
  (1) 首次使用需用户授权摄像头/麦克风；
  (2) IP 定位为城市级精度，非精确定位，用于天气自动匹配；
  (3) 建议在演示/评测场景告知用户图像采集用途。

6.3 安全加固建议
----------------------------------------------------------------
  (1) 生产环境启用 HTTPS，避免语音/文本被窃听；
  (2) API Key 存放于 backend/.env（已 gitignore，不入库）；
  (3) 后端 CORS 仅允许白名单来源；
  (4) 全局异常处理避免泄露内部错误细节。

第八部分  故障排查手册
================================================================================

8.1 前端白屏
----------------------------------------------------------------
  现象：打开页面空白。
  排查：
  (1) 检查前端是否构建：dist/ 目录是否存在；
  (2) 运行 npm run build 或 npm run dev；
  (3) 查看浏览器控制台报错。

8.2 后端无法启动
----------------------------------------------------------------
  现象：python main.py 报错。
  排查：
  (1) 确认 Python 版本 ≥3.10；
  (2) 确认已 pip install -r requirements.txt；
  (3) 检查端口 8000 是否被占用。

8.3 摄像头无画面
----------------------------------------------------------------
  现象：/emotion 无画面，提示未检测到人脸。
  排查：
  (1) 确认 camera_server.py 已启动（端口 7861）；
  (2) 确认摄像头未被其他程序占用；
  (3) 确认摄像头驱动正常（内置摄像头或 USB 摄像头）。

8.4 语音识别无响应
----------------------------------------------------------------
  现象：说话无识别结果。
  排查：
  (1) 确认浏览器为 Chrome/Edge 且联网；
  (2) 确认麦克风已授权；
  (3) 检查页面右上"语音识别就绪"状态灯；
  (4) 在龙芯 3A6000 上可使用 Whisper STT 服务进行本地识别。

8.5 TTS 无声音
----------------------------------------------------------------
  现象：有文字回复但无语音。
  排查：
  (1) 确认 tts_server.py 已启动（端口 8787）；
  (2) 检查扬声器音量与浏览器自动播放策略；
  (3) 查看"设备状态"面板当前 TTS 引擎（browser 表示服务未启动）。

8.6 AI 对话无响应
----------------------------------------------------------------
  现象：开放式问题返回"未配置 API Key"或"服务调用失败"。
  排查：
  (1) 检查 backend/.env 的 DEEPSEEK_API_KEY；
  (2) 检查 DeepSeek 账户余额；
  (3) 本地指令（控车/点歌）不依赖 Key，可先验证此类功能。

8.7 龙芯 3A6000 相关问题
----------------------------------------------------------------
  现象：龙芯 3A6000 笔记本上系统无法正常运行。
  排查：
  (1) 确认 Python 版本 ≥3.10，推荐使用 Python 3.11+；
  (2) 确认 setup.sh 已成功执行，LoongArch64 wheels 已安装；
  (3) 确认龙芯浏览器版本为 Chromium 138 内核；
  (4) 确认笔记本内置摄像头/麦克风/扬声器驱动正常；
  (5) 如遇 Python 依赖安装失败，检查网络连接或使用龙芯官方源
      pypi.loongnix.cn/loongson/pypi。

（文档完）
