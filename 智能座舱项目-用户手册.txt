第 1 章  产品简介
================================================================================

1.1 产品是什么
----------------------------------------------------------------
"智能座舱助手"是一套多模态智能座舱交互终端，把疲劳检测、表情识别、
语音对话、车辆仪表等能力集成在一个界面里，让驾驶员通过"看、说、点"
三种方式与车辆进行自然交互。

核心能力一览：
  (1) 实时车辆仪表 —— 车速、转速、油量、胎压、水温实时刷新；
  (2) 疲劳检测 —— 摄像头识别哈欠、闭眼，事件驱动语音告警，护航行车安全；
  (3) 表情识别 —— 识别开心/悲伤/愤怒/惊讶/恐惧/厌恶/平静 7 类情绪；
  (4) 语音助手 —— 说"小龙"唤醒，支持对话、控车、点歌、查天气；
  (5) 座舱控制 —— 空调、车窗、座椅加热、氛围灯、驾驶模式；
  (6) 音乐娱乐 —— 本地曲库 + 在线曲库，语音点歌；
  (7) 天气查询 —— 实时天气 + 7 天预报，支持 30+ 城市。

1.2 面向谁
----------------------------------------------------------------
  驾驶员、乘客、车机系统评测人员、产品演示人员。

1.3 一句话使用入口
----------------------------------------------------------------
  启动系统后，浏览器打开 http://localhost:5173 即可进入。

第 2 章  系统要求
================================================================================

2.1 硬件要求
----------------------------------------------------------------
  组件        最低要求                      说明
  ----------  ----------------------------  ------------------------------
  处理器      x86_64 或 LoongArch64        LoongArch 走降级路径
  内存        512MB（LoongArch 目标）       开发机建议 4GB+
  摄像头      USB/内置                    疲劳/表情识别必需（无则模拟）
  麦克风      内置/外接                   语音助手必需
  扬声器      内置/外接                   语音播报必需

2.2 软件要求
----------------------------------------------------------------
  依赖        最低版本      说明
  ----------  ------------  ------------------------------
  Python      3.10+        后端 + 摄像头服务
  Node.js     18+          前端构建与运行
  浏览器      Chrome/Edge   需支持 Web Speech API（语音识别）

2.3 网络要求
----------------------------------------------------------------
  - DeepSeek API（AI 对话，需联网 + API Key）；
  - Open-Meteo（天气，需联网）；
  - 高德 / pconline / ipinfo（IP 定位，需联网）；
  - Jamendo（在线曲库，需联网）。
  纯本地功能（仪表、座舱控制、本地音乐、疲劳检测）可离线运行。

第 3 章  安装与部署
================================================================================

3.1 Windows 安装
----------------------------------------------------------------
步骤 1：克隆代码
  git clone https://github.com/1015-jbz/smart_seat.git
  cd smart_seat

步骤 2：安装后端依赖
  cd backend
  python -m venv venv
  venv\Scripts\activate          # 或 Git Bash: source venv/Scripts/activate
  pip install -r requirements.txt

步骤 3：配置 API Key
  cp .env.example .env
  # 编辑 .env，填入 DEEPSEEK_API_KEY（从 platform.deepseek.com 获取）

步骤 4：安装前端依赖
  cd ..
  npm install

步骤 5：配置前端环境变量（可选）
  cp .env.example .env.local
  # 如需部署到其他地址，编辑 VITE_API_BASE / VITE_CAMERA_BASE

3.2 龙芯平台（LoongArch）安装
----------------------------------------------------------------
步骤 1：克隆代码
  git clone https://github.com/1015-jbz/smart_seat.git
  cd smart_seat

步骤 2：一键安装（自动适配 loongarch64）
  chmod +x setup.sh
  ./setup.sh

步骤 3：配置 API Key（setup.sh 会自动生成模板）
  vim backend/.env

步骤 4：一键启动
  chmod +x start.sh
  ./start.sh

  注意：onnxruntime 和 mediapipe 在 LoongArch 上无预编译 whl，
        会自动降级到 OpenCV Haar Cascade 人脸检测，功能完整可用，
        仅表情分类精度略降。

第 4 章  启动与访问
================================================================================

4.1 启动三个服务（开发模式）
----------------------------------------------------------------
  终端 1（后端，端口 8000）：
    cd backend && python main.py

  终端 2（摄像头，端口 7861）：
    cd backend && python camera_server.py

  终端 3（前端，端口 5173）：
    npm run dev

4.2 访问系统
----------------------------------------------------------------
  浏览器打开 http://localhost:5173

  首次打开可能需要：
  (1) 授权摄像头权限（用于疲劳/表情识别）；
  (2) 授权麦克风权限（用于语音助手）。

4.3 服务端口速查
----------------------------------------------------------------
  服务            端口   技术栈
  --------------  -----  ------------------------------
  前端 (Vite)     5173   React 19 + TailwindCSS 4
  后端 (FastAPI)  8000   FastAPI + SQLAlchemy + SQLite
  摄像头 (Flask)  7861   Flask + OpenCV + MediaPipe + ONNX
  语音合成 (TTS)  8787   Edge TTS / WinRT / pyttsx3

================================================================================
第 6 章  各功能模块使用说明
================================================================================

6.1 系统总览（首页）
----------------------------------------------------------------
  - 顶部大时钟实时显示当前时间；
  - 四张快捷状态卡：天气、车速、疲劳评分、车内温度；
  - "最近对话"卡展示最近 3 条语音/文字对话，点"查看全部"进入语音助手。

6.2 车辆仪表
----------------------------------------------------------------
  页面展示实时车辆数据，数据由后端硬件模拟器通过 WebSocket 每秒推送：
  - 车速表（中央大仪表）；
  - 发动机转速、油量、水温；
  - 四轮胎压（左前/右前/左后/右后）。
  提示：真实装车时接入 OBD/CAN 总线即可替换模拟数据源。

6.3 座舱控制
----------------------------------------------------------------
  (1) 空调控制：点击开关开启/关闭；用 +/- 按钮或滑块在 16~30℃ 调温；
  (2) 车窗控制：左前/右前/左后/右后四窗独立点击开/关；
  (3) 舒适设置：座椅加热开关、氛围灯开关、灯光六色可选；
  (4) 驾驶模式：舒适 / 运动 / 经济 三种模式切换；
  (5) 音量设置：拖动滑块 0~100 调节系统音量。

6.4 表情识别
----------------------------------------------------------------
  (1) 对准摄像头，页面自动检测人脸并绘制关键点；
  (2) 系统实时分类当前表情（开心/悲伤/愤怒/惊讶/恐惧/厌恶/平静）；
  (3) 页面展示情绪标签、置信度、emoji 与主题色；
  (4) 下方为表情历史（时间/表情/置信度）与情绪统计（占比/趋势）。

6.5 语音助手
----------------------------------------------------------------
  这是系统的核心交互入口，支持语音 + 文字双模态。

  唤醒方式（三选一）：
  (1) 任意页面点右下/右栏麦克风按钮；
  (2) 在输入框输入"小龙"并发送；
  (3) 点击快捷指令按钮"小龙"。

  说话方式：
  - 点击麦克风开始录音，说完自动识别并提交；
  - 或直接在输入框打字，回车发送。

  常用指令示例：
    开窗类   "打开全部车窗""打开主驾窗""关窗"
    空调类   "温度调到24度""降温""升温""关闭空调"
    风速类   "风量大""风量小"
    音乐类   "播放流行音乐""来一首轻音乐""暂停""下一首"
    导航类   "导航到北京站"
    天气类   "明天天气"
    通话类   "接听""挂断"
    开放式   "今天心情怎么样"（走 DeepSeek AI 对话）

  音色设置（右侧面板）：
  - 语音角色：8 种声线（晓伊/小梦/晓晓/云希/云健/云扬/晓北/晓妮），
    覆盖动漫风、温柔日常、专业播报、方言趣味；
  - 语速/音高/音量微调：三滑块各 -5~+5 格；
  - 风格预设：默认 / 新闻播报 / 有声读物 / 客服模式；
  - 试听按钮可预览当前音色，"重置微调"恢复默认。

  情绪切音：摄像头识别表情/疲劳后，TTS 会自动叠加对应音色参数，
  例如疲劳时语气更柔、更慢。

6.6 音乐娱乐
----------------------------------------------------------------
  (1) 本地曲库：自动扫描本地音乐目录 + 内置演示音轨；
  (2) 在线曲库：搜索关键词，从 Jamendo（CC 授权）返回可播放曲目；
  (3) 播放器：播放/暂停/上一首/下一首/音量/进度拖动；
  (4) 语音点歌：对语音助手说"播放 XX"，自动匹配或搜在线曲库；
  (5) 全局播放器：切到其他页面音乐仍继续播放（底部 MiniPlayer）。

6.7 安全监控
----------------------------------------------------------------
  (1) 疲劳评分：实时显示 0~100 疲劳分与等级；
  (2) 等级说明：
      normal（正常） / warning（轻度） / high（中度） / critical（重度）；
  (3) 事件驱动告警：
      - 哈欠（嘴部开合比 MAR > 0.6）→ 轻度告警；
      - 闭眼 > 2 秒 → 中度告警；
      - 闭眼 > 4 秒 → 重度告警；
      触发时系统自动语音播报提醒，疲劳评分仅作参考展示，不触发播报；
  (4) 分心检测：视线偏离、分心时长记录；
  (5) 疲劳事件历史与统计：查看历史事件、总驾驶时长、平均疲劳分等。

6.8 天气信息
----------------------------------------------------------------
  (1) 实时天气：温度、天气状况、湿度、风速、气压、能见度、紫外线；
  (2) 7 天预报：未来一周天气趋势；
  (3) 城市切换：支持 30+ 城市，IP 定位/GPS/手动选择三通道。

第 7 章  语音助手进阶使用
================================================================================

7.1 唤醒词说明
----------------------------------------------------------------
  全局唤醒词为"小龙"（拼音 xiaolong）。
  任意页面均可在右栏全局监听中说"小龙"唤起对话。

7.2 语音识别原理
----------------------------------------------------------------
  使用浏览器原生 Web Speech API（Chrome 云识别），因此：
  - 需联网且使用 Chrome/Edge；
  - 首次使用需授权麦克风；
  - 说话后识别文本自动填入输入框并提交。

7.3 语音合成原理
----------------------------------------------------------------
  后端 TTS 服务提供多引擎自动降级：
  Edge TTS（神经网络，最自然）→ WinRT 本地语音 → pyttsx3 基础语音
  → 浏览器内置语音（TTS 服务未启动时）。
  音色由"角色基准 + 情绪调整 + 手动微调"三层叠加合成。

7.4 提示
----------------------------------------------------------------
  - 若语音无反应，检查浏览器是否授权麦克风、是否联网；
  - 若 AI 回答提示未配置 Key，去 backend/.env 填 DEEPSEEK_API_KEY；
  - 本地指令（开窗/空调/风速/接听等）不依赖 AI Key，可离线使用。

第 8 章  常见问题（FAQ）
================================================================================

Q1  打开页面是白屏？
    通常前端 dist 未构建。运行 npm run dev（开发）或 npm run build 后
    用 start.bat/start.sh 启动（已含自动补构建逻辑）。

Q2  摄像头检测不到人脸？
    (1) 确认摄像头服务 7861 已启动；(2) 确认浏览器已授权摄像头；
    (3) LoongArch 平台会降级 Haar Cascade，精度略降属正常。

Q3  说话没反应 / 识别不了？
    检查：麦克风授权、联网状态、是否使用 Chrome/Edge（Web Speech API）。

Q4  疲劳评分很高但不播报？
    系统为"事件驱动"播报：仅哈欠、闭眼动作触发语音，评分本身不播报，
    属预期设计。

Q5  AI 对话总提示"未配置 API Key"？
    编辑 backend/.env，填入 DEEPSEEK_API_KEY 后重启后端。

Q6  天气/定位不准确？
    定位优先级：浏览器 GPS > 高德 IP 定位 > 手动城市选择。
    可在天气页手动切换城市。

Q7  音乐搜索不到想要的歌？
    在线曲库为 Jamendo CC 授权曲目（非全网版权库），
    可自行把 mp3 放入本地音乐目录后点"刷新曲库"。

Q8  龙芯板上很卡或浏览器报 illegal instruction？
    龙芯 2K300 缺 LSX SIMD 指令，现代浏览器可能崩溃，
    需使用 dillo 等轻量浏览器或精简构建产物。
